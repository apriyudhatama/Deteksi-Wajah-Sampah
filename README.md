# Object Detection using OpenCV

A simple object detection project for waste classification and face detection using Python and OpenCV.

## 🔍 Features
- Detect human faces
- Detect waste objects (basic classification)
- Real-time camera detection

## 🛠 Tech Stack
- Python
- OpenCV

## 🎯 Purpose
To explore computer vision techniques for real-world applications.
